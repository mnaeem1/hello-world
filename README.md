## Simple Computer Vision App
This repository now includes a small Python script, `simple_cv_app.py`, that performs edge detection on an image using OpenCV.

### Requirements
- Python 3
- `opencv-python` package (`pip install opencv-python`)

### Usage
```bash
python simple_cv_app.py <image_path> [output_path]
```
The script reads the image located at `image_path`, runs Canny edge detection, and saves the result to `output_path` (default: `edges.png`).
